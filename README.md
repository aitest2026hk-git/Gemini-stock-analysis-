# 港股/美股高精度動態交易與時空風控系統 (Stock Analysis Framework)

## 系統核心定位
本系統結合江恩理論（Gann Theory）、小龍週期與時空窗口（Solar Terms / 節氣）、技術面形態（頭肩頂/Re-test）以及動態三階段倉位風控，用於港股（恒生指數 HSI）及美股/重點標的（如阿里巴巴 09988.HK、半導體 SMIC 01347 / INTC）的波段交易與策略執行。

---

## 一、 關鍵位階與形態架構 (HSI Anchor Levels)
* **強阻力/無效化區**：25,000 點（突破需要 > 2,800 億港元大市成交額共振）。
* **Re-test 敏感區**：24,700 – 25,000 點（高利率 Higher for Longer 壓迫下的無量回抽風險）。
* **短線第一防線**：24,500 點（失守即代表短線結構轉弱）。
* **頭肩頂頸線防禦區**：23,800 – 24,000 點（中期多空生死線）。
* **空頭波段目標區**：21,600 – 22,000 點（若頸線有效失守後的下探目標）。

### 2. 半導體（SMIC 01347 / INTC）

### 3. 小龍專欄與宏觀風控邏輯
* **高利率壓迫（Higher for Longer）**：防範無風險利率企穩高位導致企業與機構資金被逼「去槓桿（De-leveraging）」。
* **Re-test 警示**：若大盤反彈至 24,800–25,000 點無量，屬跌破後的技術性回抽，需防範後續二次探底。
